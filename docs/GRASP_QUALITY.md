# 夹持控制与候选可达性实验

固定零位闭合会让大物体承受较大的持续挤压；部分方块在抬升时穿透超限，部分圆柱虽然抬起，却无法满足连续稳定保持。另一些圆柱失败来自偏向曲面边缘的接触，减小夹持力不能解决。这些功能用于抓取数据采集，仍以完整物理记录和严格后处理决定数据是否合格。

## 配置

在用于本次采集的 `runtime/config/scene.json` 中可显式设置：

```json
{
  "grip_policy": "pad-feedback-3n",
  "endpoint_screening": true,
  "contact_quality_ranking": true
}
```

这些是原有相机、初始关节和参考位置配置之外的附加字段。省略时分别使用原有零位闭合、关闭终点预筛、关闭接触质量排序。普通管线会冻结配置和源码；不要修改已登记实验的快照。

`pad-feedback-3n` 根据上一控制帧的两侧接触力，调整两个相同的绝对夹指位置目标；沿用 400 N/m、20 Ns/m 的原生 PD。反馈覆盖闭合、抬升及保持，单指目标每控制步最多改变 0.45 mm，受预开口范围约束。3 N 是两侧平均反馈参考，不能理解为每个物理子步都精确达到 3 N。`pad-feedback-5n` 仅保留为显式比较配置。所有实际命令在反馈计算后保存，8D 导出仍使用两指目标开口之和。

终点预筛在原有场景几何筛选后，按候选开口做完整世界约束下的抓取终点 IK，并核查整臂、夹指、桌面、墙及自碰撞；通过后才进入接近路径排序。它增加预处理耗时，也可能因为 IK 未找到解而拒绝实际可达的姿态。下降路径仍必须独立规划并完整核查，终点通过不等于路径通过。

接触排序使用既有橡胶接触范围内的物体表面法向。两侧法向对夹持方向的下四分位对齐程度较好时优先尝试，再按机械臂运动量排序；动态摩擦系数仅提供排序参考。它不是力闭合证明，不放宽候选资格或物理成功判据。

候选上限仍为 200 个源姿态、50 个场景几何合格姿态、5 个完整规划尝试，每个完整候选 30 秒软预算。终点 IK 和接触排序的额外耗时单独记录。

上述 200 为原实验和默认值；显式生成并接入 500／1000 个模型候选的独立对照见 [源候选数量实验](CANDIDATE_COUNT.md)。历史 256 初态实验没有更改候选预算。

## 圆柱几何先验

原始圆柱模型候选存在曲面偏边接触，圆盘模型候选在墙场景中可能没有可行姿态。可在规划 Python 环境中另建一份明确标识来源的几何候选池：

```bash
python -B tools/generate_axial_candidates.py \
  --object disk56h24 --output-root generated/axial_prior
python -B tools/generate_axial_candidates.py \
  --object cylinder36h52 --output-root generated/axial_prior
```

该工具只接受一个居中、轴向为 Z 的圆柱基元。它根据物体高度生成 20 个轴向角、5 个倾角及2个接触高度，每物体共200个姿态，并执行原有物体几何筛选。采集圆盘时显式选择 `--objects disk56h24 --candidate-root generated/axial_prior`，圆柱选择 `--objects cylinder36h52`，同时开启终点预筛。四物体混合采集的候选根目录还须包含方块和细长条的原始模型池；保留各物体的缓存及报告，不覆盖已登记实验。

这是替换候选池的几何先验，**没有调用 GraspGen，也没有新的模型置信度**。缓存不允许覆盖；不会将200个几何姿态追加到原有200个模型姿态。历史管线的目录键仍为 `graspgen`，以 `REPORT.json` 和回合元数据的 `candidate_source_kind` 为真实来源，模型候选数记录为0。混合批次必须逐物体报告来源，不能将圆柱或圆盘的结果作为纯 GraspGen 提升。

初态预检、原生夹指对外碰撞、完整几何扫掠、禁止接触限制、1 mm 接触穿透上限、120控制周期的独立稳定保持和导出读回验收均继续生效。新增配置不涉及搬运、松手或篮子任务。

## 验证记录

固定动作诊断共18次显式干预：方块穿透失败、圆柱抖动失败及各自成功对照，并包含一个细长条成功对照。3 N 和5 N反馈都修复了前两类诊断中的问题，保留成功对照，但都未修复曲面边缘滑落。历史动作回放和沿用旧抬升路径的诊断不计为正式采集合格回合。

正式复验必须重新规划闭合后的抬升，使用冻结初态清单，不替换失败、不重试物理抓取，完成全部原始记录和严格导出读回检查。多项设置同时变化时只能报告组合干预效果；各组件的因果作用需要单独消融实验。

可对任意保存回合执行 `python -B tools/audit_grip_feedback.py /完整回合目录`，不修改原始文件。它核验保存控制器的源码哈希，用上一帧接触力逐步重建反馈目标，并严格比较记录动作、重建动作和实际目标，避免漏记反馈或错位一帧。未启用反馈的回合会明确标记 `feedback_activated: false`。

完整固定初态复验及候选来源见 [256 初态验证报告](QUALITY_VALIDATION_20261117.md)。

# 本次整理的验证范围

独立版本基于当前平台采集器和 I/O v2 实现整理。交付内容只包含源码、配置和运行几何资产，未附带历史采集结果。

已验证：

- 10 项 CPU 回归测试：GPU 分配映射、120 槽常驻分组、40/72/120 槽测速兼容、点云居中恢复/TCP 适配、表面采样、几何资产加载、首回合预热与错误初态拒绝、并发规划请求隔离、真实子进程与含空格目录调度、交付内容检查。
- 仿真、规划、GraspGen 三环境的 CPU 依赖与导入检查；GraspGen 的 Panda 配置和夹爪几何加载；三个官方模型文件 SHA256 核验。未加载模型到 GPU。
- 四物品现有原始候选在整理后几何模块下逐项重算：候选变换、开口、评分、几何拒绝列表与当前版一致。这里只读取原文件核对，未复制到交付库；没有生成新的 GPU 候选。
- 现用 fast_env / fast_env_v2、成功评分模块、两种数据验证器、机器人 TCP/FK 和基础实体检查共 9 个核心文件逐字节一致；Panda URDF 与网格保持一致。环境 reset 只将历史 NPZ 中使用的关节/参考位置参数迁至 scene.json，数值保持一致。
- Python 源码语法、shell 语法、单/双/四卡计划及交付归档解压后的 CPU 回归与资源闭合检查。

尚未在新目录进行完整 GPU GraspGen 推理或新的 Isaac 物理抓取，也没有重新验证单卡显存、GUI 显示、新电脑驱动/Vulkan或首回合预热的实际修复效果。现有初态 guard 会在实际落稳后独立读取 PhysX 核对，不符合要求则保存原因并停止。请在目标机器依次执行 README 的 `check → prepare → collect --smoke`；两条验收通过后再运行长批次。

性能和成功率沿用原流程的已有经验，本次整理没有给出新的物理测试成绩。

## 2026-11-13：可选夹爪对称朝向选择

新增 `--grasp-symmetry near-first`，默认 `off`。每个源 TCP 位姿派生局部 Z 轴旋转 180° 的表示，按本次请求的实测 TCP 世界朝向分为近向/远向两组，位置和接近轴保持。每组各最多 50 个场景几何合格候选，完整规划总预算仍为 5 个、每个 30 秒软预算。

27 项 CPU 回归通过，其中新增 12 项覆盖 16→32 位姿配对、右手系/位置/Z 轴不变、世界坐标与当前姿态影响、0/90/180°及同角稳定性、父来源与指腹侧向信息、非法输入拒绝、两组独立几何检查、默认关闭、命令行/任务参数传递，以及真实 `Planner.select` 在 GPU 操作用 CPU 替身时的组优先、IK/完整路径失败后备和共享规划预算。测试不启动物理抓取。

只读原挡板杯子实验的候选 #232 和选择请求，用新代码计算目标净转角：原朝向 114.41698°，翻转朝向 76.50124°，翻转版本进入近向组。这里计算的是保存的规划目标；此前按实测最终姿态计算的 114.41404°/76.50580°包含执行误差。尚未对新朝向做新增 GPU 规划、碰撞可行性或物理成功验收，不能据此给出实际轨迹转角或速度收益。历史结果与生产评分未改。

新采集使用 `com_translation_pose_arc_v3`：由 PhysX 原生 actor-local COM 和每控制间隔的 8 个物理位姿，计算世界 COM 的累计平移路程及 SO(3) 累计转角。采集端按同一个评分器首次通过的时刻结束；校验端从回合源码快照重放。原生速度只作为有限值遥测保留。稳持阈值、120 控制间隔及碰撞限制不变。

抓取前静止证据保存在 `INITIAL_STATIC_TRACE.npz` / `INITIAL_STATIC_AUDIT.json`。仍执行原有 120 控制步（2 秒）落稳，记录末尾 31 个控制观测，以首个端点为参考测量 30 个间隔（0.5 秒、240 个物理间隔）。统一工程规则是 `平移累计路程 + 物体边界半径 × 累计转角 ≤ 0.5 mm`，且窗口内没有机器人与物体的接触。此规则是基础物体局部验收标准，不声称已覆盖任意资产。优化落稳阶段由 118 个 minimal + 2 个 full 改为 89 + 31，仅增加观测与渲染开销；不增加物理步、重置物体速度或改变物理参数。

静止不合格的初始化停止在规划前，保存失败记录，单列初始化不合格数，不进入有效抓取成功率分母。机器人在后续抓取中造成的移动照常计入抓取结果。历史数据缺少完整静止窗口时标为未知，不修改旧标签。

`run.sh export` 默认重新核验 v3 运动评分和静止证据，成功后才导出原生 LeRobot v3 并使用官方读取器逐行核对双 RGB、状态、动作和边界填充。`--allow-legacy-unverified` 仅供历史格式调试，无法通过新训练检查。

完整本地验收入口：

```bash
bash run.sh pipeline --output /absolute/new-directory --gpus 0,1,2,3 --workers 3 \
  --candidate-root /absolute/candidates --lerobot-python /path/to/lerobot/python
```

默认四种基础物体各 5 个固定槽，baseline 速度、symmetry off；全部失败保留，不补种子、不重试。流程依次执行采集、双校验、严格选择、导出、官方完整读取及 100 步 ACT 训练检查。训练检查使用双相机、测量关节状态、绝对位置目标、官方归一化和动作分块填充，保存模型、处理器、优化器与指标；它验证训练管线能消费数据，不代表闭环策略学会抓取。

`pipeline` 启动时自动把本次源码、runtime 和导出工具复制到输出目录的 `source/`，保存 `SOURCE.json` 哈希清单；所有后续阶段从该副本启动。采集中修改主工作目录不会改变该批次执行版本。

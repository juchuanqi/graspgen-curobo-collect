# 5 cm 接近距离与物理验证（2026-11-18）

新采集将预抓取位置从抓取姿态沿接近轴后退 **5 cm**，原默认值为10 cm。
抓取位置和朝向不变，接近轴不一定竖直向下。候选场景碰撞预筛与cuRobo后续
直线接近使用同一组预抓取/抓取目标。之前到预抓取位置的运动仍由cuRobo规划。

代码改动仅为 `runtime/collector/target_provider.py` 中 `world_targets` 的默认距离。
完整机械臂、手掌和夹指的世界碰撞、自碰撞、独立完整几何复核，以及桌面1 mm、
挡板6 mm的规划余量保留。冻结的历史实验使用原源码，不随新默认值改变。

## 规划失败案例复测

对[纯GraspGen500带墙物理实验](WALL_MODEL500_20261118.md)中的9个规划失败案例，
复用原始候选、实测初态、种子、baseline关节速度、场景候选50/完整候选5及
每候选30秒软预算，仅改变接近距离。5 cm找到4条通过完整几何与自碰撞检查的
接近/下降路径，4 cm找到3条。4 cm没有新增通过案例，另一个方块案例的手掌与
挡板间距约5.83 mm，不满足6 mm余量，因此选用5 cm。

两档均为每例一次求解，10 cm参照为历史记录；独立规划器初始化、GPU数值和
共享负载可能影响结果。这不是对全部32例的重新测量，也不证明距离越短越好。

每物体复用同一份官方GraspGen500模型池，未增加手写抓姿。初始物体姿态及关节
状态逐例与历史记录匹配，最大初始关节误差为0。baseline速度、accelerated执行、
3 N夹持反馈、终点预筛及接触质量排序保留。物理执行时重新规划，不强制执行离线
路径；4个成功对照最终选择的候选索引与各自历史记录一致。

抬升目标为12 cm，验收保持至少抬高6 cm、连续120个60 Hz控制周期（2秒）稳持，
并满足原速度、相对漂移、双指接触、接触力和穿透要求。物理频率480 Hz，
总控制周期上限2400。初始化重试0次、物理重试0次，不替换失败案例。

挡板接触独立统计每个控制间隔8个物理子步的机器人各连杆/手掌/夹指对挡板峰值，
以及物体对挡板峰值；任何正法向力均计为检测到接触，原评分1 N阈值不变。
两组挡板峰值均为0 N；全批最大接触穿透约0.297 mm。

原始数据、120周期稳持重放及夹持反馈动作独立核查通过；8条轨迹共10,936个
动作。8个双相机视频从原始记录生成，全部帧解码和抽样像素比较通过。
本轮未重新执行LeRobot导出、模型训练或搬运释放任务。

4个对照未观察到成功退化，但只测试了预先选定的8例、每例一次。10 cm使用
封存历史结果，并非同机同时重跑；不能外推全场景成功率、未知物体表现或吞吐。
